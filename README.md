# Moury Sultana — Beauty & Style Website

A GitHub Pages-ready static website.

## Files

- `index.html` — main website
- `style.css` — design and responsive layout
- `script.js` — menu and scroll animations
- `images/profile.jpg` — profile photo

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and the `images` folder.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Click **Save**.
7. GitHub will provide your live website URL.

No separate hosting is required.
